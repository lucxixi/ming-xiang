# 静心课 · 冥想入门课程

[![Open in Bolt](https://bolt.new/static/open-in-bolt.svg)](https://bolt.new/~/sb1-yz2fbozr)

一个面向零基础用户设计的交互式冥想入门课程，共 7 个模块，包含动态视觉、音效反馈与可持久化的打卡记录。

---

## 模块总览

| # | 模块 | 核心体验 |
|---|------|---------|
| 01 | 欢迎页 | 星空背景 + 莲花动画，课程进度展示 |
| 02 | 冥想是什么 | 破除误解、神经科学效果图、核心洞察 |
| 03 | 方框呼吸法 | 跟随律动的呼吸圆圈，4-4-4-4 节奏，音调引导 |
| 04 | 身体扫描 | SVG 人体图，点击各部位获取引导词，自动扫描模式 |
| 05 | 念头观察 | 将念头变成云朵，点击放走，感受松脱 |
| 06 | 烛火专注 | 逼真跳动的烛火动画，自定义时长，走神计数 |
| 07 | 21天打卡 | 持久化日历，连续天数追踪，成就徽章 |

---

## 技术栈

- **框架**：React 18 + TypeScript
- **构建工具**：Vite
- **样式**：Tailwind CSS + 自定义 CSS 动画
- **图标**：Lucide React
- **音效**：Web Audio API（无需外部资源）
- **持久化**：localStorage（打卡记录、课程进度）

## 功能说明

### 呼吸练习
- 实时缩放的呼吸圆圈跟随吸气 / 屏息 / 呼气节奏
- 每个阶段切换时播放不同音调提示
- 完成 1 轮后出现"够了，结束"跳过按钮
- 练习完成后触发语音播报（浏览器 SpeechSynthesis）

### 身体扫描
- 点击 SVG 人体任意部位即可获取冥想引导词
- 探索 3 个部位后"继续"按钮立即解锁，无需完成整个自动流程
- 自动引导模式每 5 秒切换一个部位，伴随音调提示

### 念头云朵
- 输入念头或从预设列表选择，变成云朵从底部飘起
- 点击云朵释放，播放上行和弦音效
- 放走第 1 个念头后即可继续下一课

### 烛火专注
- 开始前选择时长（1 / 2 / 5 分钟，或 ±30 秒自定义）
- 练习中点击"回来了"记录走神次数，有闪光音效反馈
- 随时可点击跳过按钮提前结束
- 自动计算专注得分（100 - 走神次数 × 6）

### 21天打卡
- 每天点击打卡，数据存入 localStorage 持久保存
- 自动计算连续打卡天数
- 累计 7 天、14 天、21 天解锁对应成就徽章
